卡尺 Caliper

卡尺Caliper

说出你要的零件，它来建模，每一步都实测。

用平常话描述零件，卡尺先问清楚、再分阶段建模；每一步的尺寸都由程序在沙盒里真的建出来、量出来，模型说了不算。交付 STEP、STL 和参数化的源文件。

名称卡尺 Caliper
版本2.0.0
建模内核SimpleCADAPI 2.2.7
形态桌面应用
01

安装

Windows 在 PowerShell 里粘贴

irm https://raw.githubusercontent.com/DingZhen-zhr/computer-graphics-project/master/install.ps1 | iex

Mac 在“终端”里粘贴

curl -fsSL https://raw.githubusercontent.com/DingZhen-zhr/computer-graphics-project/master/install.sh | sh

Windows 10/11（64 位），或 Apple 芯片的 Mac（macOS 14 及以上）。需要一个大模型服务的 API key，推荐 DeepSeek。

不需要管理员权限，也不用先装 Python。装不上时看说明里的“装不上怎么办”。

02

它怎么工作

  1. 01澄清你用平常话说要什么零件；它把尺寸、用途、各部分怎么相接问清楚，整理成一张需求单。
  2. 02确认需求单连同每个参数的来源、各部分的位置关系摆在你面前，你点了确认它才动手。
  3. 03规划把零件拆成几个阶段，每个阶段写明做完以后零件上多了什么。
  4. 04逐阶段建模与实测每个阶段先写检查、再写建模代码，由程序真的建出来并测量；检查全过才进入下一阶段。
  5. 05终检与交付全部检查再跑一遍，再把每个参数挨个改一改，确认它真的管着几何，然后交付文件。
