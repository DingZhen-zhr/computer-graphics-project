Datum 基准

Datum

说出你要做的东西，它来建模，每一步都实测。

一个零件，或者几个零件装在一起、能动的东西。它先把需求问清楚，再一步一步建出来；每一步的尺寸都由程序在沙盒里真的建出来、量出来，模型说了不算。交付 STEP、STL 和参数化的源文件。

在线看一个示例 在 GitHub 上看源码和说明

安装

Windows 在 PowerShell 里粘贴

irm https://raw.githubusercontent.com/DingZhen-zhr/computer-graphics-project/master/install.ps1 | iex

Mac 在"终端"里粘贴

curl -fsSL https://raw.githubusercontent.com/DingZhen-zhr/computer-graphics-project/master/install.sh | sh

Windows 10/11（64 位），或 Apple 芯片的 Mac（macOS 14 及以上）。需要一个大模型服务的 API key，推荐 DeepSeek。

不需要管理员权限，也不用先装 Python。装好的是 3.0.0 版。装不上时看说明里的"装不上怎么办"。

它怎么工作

  1. 问清楚你用平常话说要做什么；它把尺寸、用途、各部分怎么连、哪里会动问清楚，边问边把需求单填在画面中间。
  2. 确认每个尺寸都标着是你给的还是它建议的；你点了"没问题，开始做"它才动手。
  3. 一步步做、每步实测把每个零件拆成几步，每一步先写好要量什么，再建出来、真的量一遍；量过了才做下一步。
  4. 装起来、动起来检查几个零件按真实的面和轴装在一起，检查有没有穿模；会动的地方从头到尾取几十个位置，每个位置都检查碰撞。
  5. 交付最后把每个尺寸改一改，确认检查真的管得住它，然后交付文件；之后可以直接改数值，不花钱。

Datum 基准是 AICG 课程 Project 3 的作业：一个用 SimpleCADAPI 建模的 CAD 智能体。
