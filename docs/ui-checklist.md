# 界面清单（3.0 展台）

每个画面都要满足下面十条。结论是 3.0 计划 3 收尾时在应用内置浏览器里看的结果（Windows，1100×700；1600×1000 和 Mac 没有看）。

| # | 要求 | 结论 |
|---|---|---|
| 1 | 颜色只用 `tokens.css` 的变量 | 符合：`test_colors_only_in_tokens`、`test_no_color_literals_in_js` 都过；材料色来自 motion.json 的数据 |
| 2 | 零件或产品始终是画面最大的东西；浮层不挡住它的中心 | 符合：调参数面板打开时舞台往上让；抽屉在两边 |
| 3 | 主要按钮一个画面最多一个 | 符合：需求单"没问题，开始做"、调参数"应用"、菜单"做一个新的"各在自己的画面里 |
| 4 | 数字用 Archivo、等宽数字、带单位 | 符合：大数字、参数、运动条的值都用 `.num` |
| 5 | 状态不只靠颜色 | 符合：检查写"量过，对 / 没过 / 没做"，零件清单写"✓ / 正在做 / 没开始" |
| 6 | 空状态有一句说明和一个下一步 | 符合：新会话的欢迎句和三个例子；检查、版本、对话记录空的时候各有一句 |
| 7 | 出错时说清发生了什么、可以怎么做 | 符合：三维加载失败退回截图并说明；运动数据坏了退回装好时的样子 |
| 8 | 键盘能到达所有能点的东西；焦点有描边；Esc 收起浮层 | 符合：抽屉、调参数、对比都能 Esc 关；焦点描边 2px 强调色 |
| 9 | 浅色、深色都看过；文字对比度不低于 4.5:1 | 符合（偏离 D35 加深了浅色的次要文字） |
| 10 | 1100×700、1600×1000 都看过 | 1100×700 看过（单零件、多零件）；1600×1000 没有单独看 |
