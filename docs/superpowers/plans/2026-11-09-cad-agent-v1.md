# CAD 建模智能体第一版 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 做出一个命令行 CAD 智能体：自然语言需求 → 追问确认 → 按特征生成 SCA 模型 → 程序检查 → 失败自动重试 → 交付 STEP，并支持多轮修改；附带 3 个测试任务的自动评测。

**Architecture：** 程序掌握流程和关卡，模型只做判断。需求单是参数的唯一来源；模型通过工具增删特征代码和检查项；程序拼出 marimo notebook，在英文临时目录的独立子进程里运行并测量，再把结果翻译后交回模型。

**Tech Stack：** Python 3.13、simplecadapi 2.2.7（含 editor、verify 附加包）、openai SDK（OpenAI 兼容接口）、PyYAML、pytest。

**Spec：** `docs/superpowers/specs/2026-11-09-cad-agent-design.md`

**原文照抄的内容：** `docs/superpowers/plans/2026-11-09-cad-agent-v1-prompts.md`。其中包括系统提示词、工具说明、模拟用户提示词、速查表格式，一律逐字复制，不改写。

**执行规则：** 见项目根目录 `CLAUDE.md`。执行者每开始一个任务前，都要先重读该任务和 Global Constraints。

## Global Constraints

- Python `>=3.10,<3.14`；本机 Windows 11 + Python 3.13.7；虚拟环境 `.venv`，命令一律用 `.venv\Scripts\python`。
- 依赖固定 `simplecadapi[editor,verify]==2.2.7`；如果 Task 1 证实 verify 装不上，就改成 `simplecadapi[editor]==2.2.7`，并在 `docs/sca-api-notes.md` 写明。
- 所有面向用户的文字、提示词、工具说明、报错翻译都用中文，用平常话。
- API key 只从环境变量读取，变量名由配置决定（默认 `DEEPSEEK_API_KEY`）；不写进代码、配置、日志，也不传给子进程。
- 默认值：运行超时 60 秒；每轮用户消息内建模失败最多 3 次；工具调用最多 40 次；长度容差 ±0.1 mm；角度容差 ±0.5°。
- 需求单单位只允许 `mm`、`deg`、`1`（个数等无量纲量）。
- notebook 的 id 固定为 `model`，产品变量名也是 `model`。
- 特征代码里不允许 `import`；`scad`、`ql`、`math` 已由程序导入。
- 坐标约定（写进提示词，验收检查依赖它）：零件底面贴在 z=0 平面；零件在 xy 平面上大致以原点为中心；最长的水平方向沿 x；有"正面"的零件正面朝 -y。
- 相对设计文档的一处细化：**参数只在需求单里维护一份**，notebook 的参数 cell 由需求单自动生成。因此取消 `set_params` 工具，改用 `update_brief` 修改参数；改了需求单就等于改了模型参数。
- 每个任务结束时提交一次 git（Task 1 中执行 `git init`）。
- Windows 编码：所有文件读写显式写 `encoding="utf-8"`；启动子进程时，环境变量加上 `PYTHONUTF8=1`，读取输出也用 `encoding="utf-8"`。

## Review Focus

1. 用户确认时附带修改（"可以，但角度改成 70"）不能算确认，应当把这句话转给模型处理。→ Task 10 `test_mixed_confirmation_not_accepted`
2. 模型给出不合法的 JSON 参数，或调用了不存在的工具：返回中文错误，程序不崩，并计入工具调用次数。→ Task 9 `test_malformed_args`、`test_unknown_tool`
3. 用户用 cm 或英寸描述尺寸：需求单拒收非 mm 单位，并提示模型先换算。→ Task 2 `test_patch_rejects_unknown_unit`
4. 会话目录在中文路径下：运行放在英文临时目录，产物复制回会话目录，STEP 和截图都要能生成。→ Task 6 `test_exports_into_chinese_dir`
5. 模型 API 断网或限流：先重试，仍然失败就告诉用户，需求单和特征都不丢。→ Task 8 `test_network_error_raises_llmerror`、Task 10 `test_llm_error_preserves_state`

### Task 4：检查项格式

**Files：** Create `cad_agent/checks/__init__.py`、`cad_agent/checks/spec.py`；Test `tests/test_check_spec.py`

**Interfaces：**
- Produces（纯 Python，不依赖 SCA）：
  - `CHECK_TYPES = {"bbox","count","angle","point_inside","point_outside","distance","volume"}`
    （相对设计文档新增 `volume`：方向无关，方便验收）
  - `Check(id: str, type: str, args: dict, expected: str | float | None, tol: float | None, op: str, refs: set[str])`
  - `CheckResult(id, type, passed: bool, measured: float | None, expected: float | None, tol: float | None, detail: str)`，带 `to_dict` / `from_dict`
  - `parse_checks(raw: list[dict], param_names: set[str]) -> list[Check]`：结果总是以三条必做检查 `valid`、`single_solid`、`positive_volume` 开头
  - `eval_expr(expr: str | float, values: Mapping[str, float]) -> float`
  - `missing_coverage(checks: list[Check], user_params: set[str]) -> set[str]`
  - `CheckSpecError(ValueError)`
- 原始检查项格式（模型通过 `set_checks` 写入）：
  - `bbox`：`{"id","type":"bbox","axis":"x|y|z","expected":expr,"tol"?}`
  - `count`：`{"id","type":"count","kind":"faces|edges","where":[[path,op,value],...],"expected":expr,"op"?}`，`op ∈ {"==",">=","<="}`，默认 `"=="`，不设容差
  - `angle`：`{"id","type":"angle","a":where,"b":where,"expected":expr,"tol"?}`。a、b 各自至少要选中 1 个平面，各取面积最大的一个，结果为两者法向的夹角，范围 0–180°。选中 0 个时算作不通过
  - `point_inside` / `point_outside`：`{"id","type":...,"point":[expr,expr,expr]}`
  - `distance`：`{"id","type":"distance","a":{"kind","where"},"b":{"kind","where"},"expected":expr,"op":"==|>=|<=","tol"?}`
  - `volume`：`{"id","type":"volume","expected":expr,"rel_tol"?}`，相对容差默认 0.01
  - `where` 的规则：`path` 必须以 `geom.` 开头；`op ∈ {"==","!=",">=","<=",">","<"}`；`geom.type` 的值是大写字面量，其余的值是表达式

### Task 5：测量引擎

**Files：** Create `cad_agent/checks/engine.py`；Test `tests/test_engine.py`（全部标记 `sca`）

**Interfaces：**
- Consumes：`Check`、`CheckResult`、`eval_expr`（Task 4）；`docs/sca-api-notes.md` 中"包围盒、面和边的属性、有效性"三节。
- Produces：
  - `run_checks(solid, checks: list[Check], values: Mapping[str, float]) -> list[CheckResult]`：每条检查各自捕获异常，出错的检查算作不通过，原因写进 `detail`
