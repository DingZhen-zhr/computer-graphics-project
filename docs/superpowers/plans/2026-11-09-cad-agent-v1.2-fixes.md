# CAD 建模智能体 · 1.2 补丁计划（修正评测问题 + 一条程序规则）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 修掉第 1.1 版评测里查出来的三个问题，然后在修正后的评测上重跑基线和新版，重新对照成功标准。

**为什么改**（详见 `docs/results-v1.1.md`，以及 Opus 对日志的核查）：
1. **模拟用户不知道修改。** 留出任务 enclosure 的修改轮里，模型把 `wall_t` 改成 3，同时改了两个建议值，于是要重新确认需求单。模拟用户拿手里没更新的隐藏需求（"侧壁厚 2 mm"）去核对，又把 `wall_t` 改回了 2。日志"本版变化"里能看到 `wall_t: 2 → 3`，接着又是 `wall_t: 3 → 2`。这是评测脚本的问题，不是智能体的问题。
2. **L 形支架的隐藏需求有歧义。** "立板 60 长"没说清楚含不含底板的厚度，模拟用户也答不清楚，导致立板叠在底板上面（总高 65）的情况反复出现。验收和体积手算按的是"立板下端和底板这一端重叠、总高 60"。
3. **建模阶段可能带着没 build 的改动结束一轮。** E2 的 phone_stand 有一遍：模型改了角度，也改了组成部分的文字，所以不满足自动重建的条件；模型却对用户说"程序会自动重新建模"，结果这一轮没有 build 就结束了。

**执行规则：** 照 `CLAUDE.md`。第 1.1 版计划的 Global Constraints 全部继续有效。偏离记录接着编号（从 D9 开始）。

**这次不做：** 不改提示词，不做提示词迭代，不放宽 C2（自动重建）的条件。只是改了组成部分文字的情况，交给下面 Task 3 的规则兜底。
