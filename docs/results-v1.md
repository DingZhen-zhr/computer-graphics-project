# 第一版联调结果

日期：2026-11-09　模型：`deepseek-flash`（DeepSeek，OpenAI 兼容接口 `https://api.deepseek.com`，temperature 0.2）
软件版本：Python 3.13.7、simplecadapi 2.2.7、openai 3.46.0、marimo 0.25.2、Windows 11。
模拟用户用的是同一个模型。运行命令：`python -m benchmarks.run --config config.toml`。

## 说明

- 没有达标不了的项，所以按计划“最多迭代 3 轮提示词”这一步没有用上，提示词和速查表保持第一版原样。
- L 形支架的体积实测 26138.6（期望 26316，偏差 -0.7%，在 3% 容差内），主要是倒角带来的差别。
- 费用方面：l_bracket 一个任务就用了约 64 万 token，主要是每次调用都带完整对话和系统提示词；后续可以考虑压缩历史。
- 一次评测只跑了一遍，没有重复，所以不能说明稳定性；换模型、多跑几遍再对比是第二版的内容。
- 评测原始输出（`benchmarks/results/`）被 `.gitignore` 忽略，没有上传。
- `/view`（`sca edit`）在浏览器里的实际显示效果还没有人工看过。
