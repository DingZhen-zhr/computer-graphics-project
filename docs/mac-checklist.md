# 卡尺 Caliper · Mac 人工验证清单

给有 **Apple 芯片（M1 及以后）Mac** 的组员照着做。持续集成只能自动跑测试和安装脚本，界面看起来、用起来对不对，要靠人看一遍。

**怎么填：**

- 每做完一项，把 `- [ ]` 改成 `- [x]`，在"看到了什么"后面写一两句：看到了什么、用了多久、哪里不对。
- 有问题的项，截图放进 `docs/walkthrough-mac/`，在这一项里写上文件名。
- 做完把这个文件发回来（或直接提交）。

**注意：**

- 整个过程**不需要真实的 API key，也不花钱**：建模用的是假模型剧本，沙盒是真的。
- 第 7 项会用到 `scripts/demo_script.json`，先从仓库里把它下载到"下载"文件夹。
- 不要在这个清单里写任何 key。
