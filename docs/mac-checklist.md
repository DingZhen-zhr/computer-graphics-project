# Datum 基准 · Mac 人工验证清单

给有 **Apple 芯片（M1 及以后）Mac** 的组员照着做。持续集成只能自动跑测试和安装脚本，界面看起来、用起来对不对，要靠人看一遍。

**怎么填：**

- 每做完一项，把 `- [ ]` 改成 `- [x]`，在"看到了什么"后面写一两句：看到了什么、用了多久、哪里不对。
- 有问题的项，截图放进 `docs/walkthrough-mac/`，在这一项里写上文件名。
- 做完把这个文件发回来（或直接提交）。

**注意：**

- 整个过程**不需要真实的 API key，也不花钱**：建模用的是假模型剧本，沙盒是真的。
- 第 7 项会用到 `scripts/demo_script.json`，先从仓库里把它下载到"下载"文件夹。
- 不要在这个清单里写任何 key。

## 发现的问题

- 第 3/5 项（引导页）：引导进度条 `.ruler.steps` 与舞台步骤栏 `stage.css` 的 `.steps`（`position: fixed`）类名冲突，导致“1 模型服务 / 2 密钥 / 3 完成”错位叠在“智谱 GLM / Kimi”选项上（截图：`docs/walkthrough-mac/onboarding-steps-overlap.jpg`）。已将 `stage.css` 限定为 `#steps` 并加测试 `test_stage_steps_do_not_hijack_onboarding_ruler` 修复。
- 桌面端实测（代理与输入框）：① macOS 开启 SOCKS5 系统代理时，`httpx2` 缺 `socksio` 导致打开会话反复弹出“服务内部出错了，可以刷新页面再试”（截图：`docs/walkthrough-mac/socks5-server-error.jpg`），经用户同意新增 `socksio>=1.0` 依赖（D49）修复；② 底部胶囊输入框点击聚焦时，WebKit 的 `:focus-visible` 黑框画在内层 `textarea` 上与外层胶囊未对齐（截图：`docs/walkthrough-mac/prompt-focus-misalign.jpg`），已改在 `.prompt:has(textarea:focus-visible)` 上描边并加测试 `test_prompt_focus_outline_is_on_capsule` 修复；③ 示例会话底部提示语在 600px 宽度下折到第二行被截断并冒出滚动条（截图：`docs/walkthrough-mac/demo-prompt-clip.png`），已将 `.prompt` 宽度上限调至 `680px`、字号 `14px`、禁用态 `overflow: hidden` 并加测试 `test_prompt_fits_demo_note_without_scrollbar` 修复。
- 第 13 项（Mac 下载 STEP）：`pywebview 6.2.1` 默认 `ALLOW_DOWNLOADS = False`，其 macOS `DownloadDelegate` 未声明 `WKDownloadDelegate` 协议，且严格 CSP 拦截 `window.pywebview` 注入。改为后端提供 `POST /api/sessions/<id>/download` 将白名单文件保存到 `~/Downloads`（重名自动加序号）、页面提示“已保存到‘下载’文件夹：<文件名>”并在访达 `open -R` 选中文件（测试 `test_download_saves_to_downloads_and_reveals`）。
- 第 17 项（多零件名字标签）：对称零件中心落在屏幕中线附近时，`layoutLabels` 按 `p.x < width / 2` 无迟滞切换导致标签左右跳动。已为 `layoutLabels` 加 `24px` 中线迟滞区并在 `assembly.js` 记住上一帧所在侧（测试 `test_labels_keep_side_within_deadband`）。
